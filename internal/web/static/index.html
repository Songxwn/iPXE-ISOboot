概览

使用步骤：

  1. 把 iPXE 引导文件（undionly.kpxe、ipxe.efi 等）放入 data/tftp/ 目录（首次运行会自动尝试下载，也可手动放置）。
  2. 确保内网存在 DHCP，并在“设置”中开启 ProxyDHCP；或在你的 DHCP 中把 next-server 指向本机、启动文件设为对应 iPXE 文件。
  3. 在“ISO 管理”上传镜像并分析、提取引导文件。
  4. 在“启动菜单”添加启动项。目标机器网络启动即可看到菜单。
