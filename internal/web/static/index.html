工作原理（Ventoy 思路的网络实现）

  1. 客户端 PXE 启动 → ProxyDHCP/你的 DHCP 下发 iPXE。
  2. iPXE chain 到本服务，按固件加载 GRUB2（BIOS/UEFI）。
  3. GRUB2 读取动态 grub.cfg，用 loopback 挂载 HTTP 上的 ISO 直接引导。

需在服务器安装 GRUB2 工具以生成网络镜像：apt install grub-efi-amd64-bin grub-pc-bin grub-common
